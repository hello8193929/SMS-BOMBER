آموزش مقدماتی Bash و Bomber

Bash چیست؟

Bash (بش) یک مفسر خط فرمان در سیستم‌عامل‌های مبتنی بر لینوکس و یونیکس است. با استفاده از Bash می‌توان اسکریپت‌هایی نوشت که کارهای مختلف را به‌صورت خودکار انجام دهند؛ مانند مدیریت فایل‌ها، اجرای دستورات، یا انجام وظایف تکراری. یادگیری Bash یکی از مهارت‌های پایه برای علاقه‌مندان به لینوکس، برنامه‌نویسی و امنیت سایبری است.

اسکریپت Bash چیست؟

اسکریپت Bash یک فایل متنی با پسوند ".sh" است که شامل چند دستور Bash می‌شود. این دستورات به‌ترتیب اجرا شده و می‌توانند کارهای مختلفی مانند ساخت پوشه، کپی فایل‌ها، نمایش اطلاعات سیستم یا اجرای برنامه‌ها را انجام دهند.

Bomber چیست؟

اصطلاح Bomber معمولاً به برنامه‌هایی گفته می‌شود که تعداد زیادی درخواست یا پیام را به یک هدف ارسال می‌کنند. این ابزارها می‌توانند برای آموزش، تست نرخ درخواست (Rate Limiting)، یا بررسی مقاومت نرم‌افزارها در محیط‌های آزمایشی استفاده شوند. استفاده از چنین ابزارهایی علیه افراد یا سرویس‌ها بدون مجوز می‌تواند غیرقانونی و غیراخلاقی باشد. بنابراین، از آن‌ها فقط در محیط‌های آموزشی یا روی سیستم‌هایی که مالک آن هستید یا اجازه آزمایش آن‌ها را دارید استفاده کنید.

هدف این پروژه

این پروژه صرفاً برای تمرین و آشنایی با اسکریپت‌های Bash، یادگیری ساختار فایل‌های ".sh" و آشنایی تئوری با ابزارهای Bomber تهیه شده است. هدف آن آموزش مفاهیم پایه و افزایش مهارت در Bash است و نباید برای آسیب رساندن یا ایجاد مزاحمت برای دیگران مورد استفاده قرار گیرد.

چگونه یک اسکریپت Bash را اجرا کنیم؟

ابتدا وارد پوشه‌ای شوید که فایل اسکریپت در آن قرار دارد:

cd مسیر/پوشه

سپس به فایل اجازه اجرا بدهید:

chmod +x script.sh

در نهایت اسکریپت را اجرا کنید:

./script.sh

یا می‌توانید مستقیماً با Bash اجرا کنید:

bash script.sh

جمع‌بندی

یادگیری Bash می‌تواند نقطه شروع خوبی برای ورود به دنیای لینوکس، اتوماسیون و امنیت سایبری باشد. هنگام کار با هر ابزار یا اسکریپت، قوانین، اخلاق حرفه‌ای و حریم خصوصی دیگران را رعایت کنید و از پروژه‌های آموزشی فقط در محیط‌های مجاز استفاده نمایید.
